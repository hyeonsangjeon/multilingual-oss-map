Where non-English open source lives — a language map

Each region is shaded by the non-English language with the most repositories there, for the selected text source. Switch source and watch the map change. English is excluded (it is global — and absent from the source data).

The asymmetry: README rank ↔ Issue rank

Each line links a language's rank in READMEs to its rank in issues. Lines that cross steeply are the story: documented in one register, discussed in another.

Language detail

Pick a language on the map, the slope chart, or here. Numbers reflect the current strictness. Medians are shown because star counts are extremely long-tailed.
